# Vaninha study environment Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans for inline implementation and a final independent review.

**Goal:** Provide Vanessa a dedicated protected chemistry study environment in its own GitHub repository.
**Architecture:** Buildless HTML/CSS/ES modules; credentials derive a key locally to decrypt learning data and original documents. Generic UI stays public. Content sources stay outside the repository.
**Tech Stack:** Node.js, Web Crypto, browser storage, native node:test, GitHub Pages.
**Spec:** ../specs/2026-11-14-vaninha-design.md

## Global Constraints
- Portuguese UI, five unique original lists, all original body images retained.
- No plaintext password or learning package in Git; separate repository.
- Local progress only; wrong credentials must not unlock material.

## Review Focus
- Incorrect credentials or corrupted bundle must fail without partial rendering.
- Empty topic selection cannot start an exam; count cannot exceed available questions.
- Unanswered exam questions enter review; a later correct practice answer clears them.
- Corrupt or unavailable storage must not prevent study.
- Formula images must remain readable at mobile widths and enlarge on demand.
